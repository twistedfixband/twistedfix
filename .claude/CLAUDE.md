# Twisted Fix

This repo is the Twisted Fix band website. Aaron runs it.

## Check the project first

Aaron uses one Claude account for the band and for MOMNT Ads, his ad agency, and Claude in Slack sometimes opens this repo for MOMNT work.

If the request is about anything other than the band (ads, ad accounts, Meta, Shopify, stock, budgets, creatives, dashboards, a client, client messages, meeting notes), this is the wrong project. Before anything else:

1. Call the `add_repo` tool with owner `momnt-ads`, repo `momnt-clients`, access `push`.
2. Run the clone command it returns, then call `register_repo_root` with that path.
3. Read `CLAUDE.md` in that clone and follow it for the rest of the session. Work, commit and push only there.
4. Change nothing in this repo.

If it's unclear which one the request is about, ask in one line: band or MOMNT?
